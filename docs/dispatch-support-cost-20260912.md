## 发布前新增修复

- 迟到消息：派送恢复持久保存原基线及无回执/产物证据，整批预检在异步读取前后复核；迟到轮次、回执或产物会阻断整组，测试确认发送数为 0。
- 完成项保护：接收 DONE 回执时记录该任务产物哈希；后续定点返修必须匹配原始记录，不接受调用者重新计算被改动文件后作为新基线。缺少原始证据的旧运行拒绝恢复，不补造历史。
- 跨项目入口：start 直接传入 barrier 路径，让统一校验拒绝相对路径，与 release 行为一致。

新增复现测试先产生 4 项失败，再修复到通过。最终全库命令为 Node.js 的 `--test test/*.test.mjs`：**90 项，89 通过，0 失败，1 跳过**。跳过项是 Windows 权限不足的 barrier symlink 用例；不把跳过当作通过。其他路径/junction 检查有独立测试。源码语法检查与 git diff --check 通过；Skill 源码和已安装版本均通过 quick_validate。

这批恢复边界修复发生在真实桌面测试之后，使用聚焦故障回归及最终全库验证，没有重跑已验收的三项目任务。旧运行状态、首次失败、收据、产物和捕获证据保留，不能宣称最终补丁已经再次经历完整桌面实测。应用层检查仍不是操作系统沙箱或跨工具读取隔离。
