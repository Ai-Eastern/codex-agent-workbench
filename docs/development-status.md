## 接续记录格式

每条记录只包含：日期、任务 ID、确切提交、结果、验证命令与证据、未验证边界、下一任务。把真实 UUID、本机路径、原始对话、凭据和私有项目资料保存在本地。未执行的测试写“未运行”，旧测试写明对应历史提交。

历史验证资料仍位于 docs/ 原有报告中，只适用于各自记录的提交和环境。现有实验 PR #1 的独立前端方向不作为新版实现基线。
