# 明确派工、自动回执与输出预算

本轮落实三项改动：派工给出具体需求与完成标准；程序生成任务结果回执；对较长 CLI 输出提供有预算的展示。保留现有桌面任务、模型与三种路线，不新增调度层或依赖。复用依据见[决策记录](dispatch-efficiency-reuse-20260912.md)。

## 已落地行为

**派工入口。** 更新 handoff 规则，GM 从已明确的项目计划接续需求，传递目标、完成标准、配置、最新 delivery 和必要限制；不把“自行找一个任务证明流程”下放给 PM。计划就地维护，不增加阶段卡文件、准备开始消息或批准轮。缺少真实需求时如实定位缺口，知识和计划不能扩大授权。

**自动回执。** 新增 `submit`，从已登记配置和冻结任务读取身份、独占文件、知识 ID，计算文件 SHA-256 并生成结果。调用者必须是实际分配角色，且显式绑定当前 attempt；旧 attempt、暂停、未派工、缺失产物和重复回执会被拒绝。生成的产物哈希在后续收集时复核。Native 须已绑定真实子任务；Desktop 须已收到派送应答，收集仍等待其实际轮次完成。

新 CLI 生成的任务包包含 resultTool 调用入口。旧包和旧手写回执继续兼容，不回写既有证据。仍保留 `--attempt` 的理由是防止迟到的旧任务把结果提交到返修后的新 attempt；身份字段无需再抄入 JSON。`SUBMITTED` 只表示结果写入，不表示验收通过；工具不补造 tests/PASSED，真实自测记录和 PM 正式验收职责保持不变。

**按需展示。** `--view compact` 自动保存完整结果到配置的 `controlRoot/views`，返回路径及哈希。默认最大 12,000 个序列化字符，预算包含展示元数据。search 保留命中知识的正文、ID、路径与哈希；完整 source 证据在详情中。start/packet/claim 保留完整执行 prompt，去掉其中已经重复的结构化展示；contextHash 明确仍属于完整检索 context。

预算不足时返回 `needsRead:true`，要求读取已保存详情后再行动，不能把不完整合同作为可执行任务。不会重排、截短知识正文或修改已冻结包。旧默认输出、continue 的唯一正式验收及 `--output` 交付语义不变。错误路径同样提供详情哈希；保存失败保留原错误及禁止自动重试提示，避免为取得输出重复执行原命令。

## 同一份历史输出的只读回放

选取上一项真实交付保存的原始 search、start、continue 结果，应用新展示函数。没有重新运行产品命令、模型或验收。

| 输出 | 原序列化长度 | 新展示长度，含引用 | 变化 |
|---|---:|---:|---:|
| RAG search | 9,849 | 4,543 | **减少 53.87%** |
| 开工 start | 15,800 | 6,584 | **减少 58.33%** |
| 完成 continue | 3,454 | 3,745 | 增加 8.43% |

三项均未触发 needsRead；回放核对 RAG 正文及来源 ID/路径/哈希、开工 prompt 与原始值相同。长度口径为 `JSON.stringify(value,null,2).length`（UTF-16 码元，包含元数据），不是 Token 或费用，也不是整段上下文减少率。数值包含此次回放详情路径长度，其他路径的开销会略有不同。

较小输出会增加详情引用的开销，因此安装版 Skill 优先对 search/start/packet/claim 使用 compact；较短 status/continue/delivery 通常保留默认。此回放证明展示减少，尚未证明 PM 准备耗时、整轮 Token 或返工率下降。

## 验证与边界

最终全套 `node --test test/*.test.mjs`：**145 项，144 通过、0 失败、1 项既有平台跳过**，约 3.68 秒。新增 18 项测试覆盖自动提交身份与状态、过期 attempt、覆盖保护、产物变化、Windows 路径、三路线收集、真实 CLI 衔接、原输出兼容、错误详情绑定、知识正文及执行提示不丢失、最终序列化预算。

开发中保留了新接口尚未存在的初始失败，以及错误详情缺少哈希的定点复现；后者修复后通过。独立检查提出的 Windows 路径疑点经合法反斜杠合同用例排除，原实现两侧都做了规范化。没有为此修改旧业务产物或重开历史失败批次。

验证级别是本地自动化和历史输出回放，Desktop 分支采用有界适配器测试；本轮没有新增真实多 Agent 并行运行或宣称整体提速。Skill 和路径检查仍不是桌面全部工具的读取隔离。完整展示文件只保存在本地，不自动删除已有证据。
